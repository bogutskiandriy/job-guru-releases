# Job Guru: releases

Job Guru is a Mac app that finds vacancies on job boards, tailors your CV and cover letter to each one and applies for you. Your data stays on your Mac.

- Site and first-launch guide: https://getjob.guru
- Download: the latest build is under [Releases](../../releases/latest). Apple silicon: the `arm64` DMG. Intel: the `x64` DMG.
- Price: free for 7 days, then one payment for a license key at https://buy.getjob.guru

This repository holds the builds only.
